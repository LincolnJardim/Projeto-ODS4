# 📚 Projeto ODS 4 — Aprendendo para Ensinar

Projeto extensionista desenvolvido com foco no **ODS 4 — Educação de Qualidade**, da ONU.  
O objetivo do projeto é aproximar alunos e professores do universo da tecnologia através de conteúdos gratuitos, incentivo ao aprendizado e divulgação de oportunidades na área de TI.

---

## 🌎 Sobre o Projeto

O projeto foi desenvolvido após uma pesquisa realizada na Escola Estadual Cidade de Hiroshima, onde foram identificadas dificuldades relacionadas a:

- Infraestrutura tecnológica
- Capacitação de professores
- Acesso ao conhecimento em tecnologia
- Engajamento dos alunos

Com base nisso, foi criado um site educativo contendo:

- Explicações sobre programação
- Plataformas gratuitas de estudo
- Ferramentas usadas por professores
- Informações sobre o mercado de trabalho em tecnologia
- Registro fotográfico do projeto

---

## 🎯 Objetivos

- Incentivar o ensino de tecnologia nas escolas
- Apresentar caminhos gratuitos para estudar programação
- Mostrar oportunidades de carreira na área de TI
- Auxiliar professores e alunos com materiais acessíveis
- Desenvolver inclusão digital através da educação

## 🌐 Como Publicar no GitHub Pages

Após criar seu fork:

### 1️⃣ Faça o fork do projeto

Clique em:

```txt
Fork
```

no canto superior direito do GitHub.

---

### 2️⃣ Clone o repositório

```bash
git clone https://github.com/seu-usuario/Projeto-ODS4.git
```

---

### 3️⃣ Faça suas alterações

Você pode:
- Melhorar o CSS
- Criar animações
- Adicionar JavaScript
- Melhorar o layout
- Criar novas páginas

---

### 4️⃣ Envie para o GitHub

```bash
git add .
git commit -m "Minha melhoria no projeto"
git push
```

---

### 5️⃣ Ative o GitHub Pages

No GitHub:

```txt
Settings → Pages → Deploy from Branch
```

Depois selecione:

```txt
main / root
```

O GitHub irá gerar um link público para seu site.
